Una plataforma para centralizar la gestión académica

GeClau (Gestión de Clases y Aulas) es el software académico de Grupo6S para universidades que necesitan ordenar su gestión de aulas, horarios y clases desde una sola plataforma.

La solución centraliza la información académica vinculada a horarios, materias, comisiones, profesores, eventos y asignación de aulas, reduciendo la dependencia de planillas y mejorando la visibilidad operativa.

GeClau también permite publicar agenda y horarios, administrar usuarios y roles, y ofrecer vistas de horarios para pantallas o entornos tipo TV. El proyecto surgió a partir de una necesidad real de la Universidad Tecnológica Nacional — Facultad Regional Mar del Plata y actualmente se encuentra implementado allí para acompañar la gestión académica.

Funcionalidades principales

Software para gestionar horarios, aulas y operación académica

GeClau está orientado a universidades que necesitan centralizar la gestión académica y ordenar procesos que suelen dispersarse entre planillas, sistemas aislados y comunicación manual.

Planificación académica

Reúne la gestión de horarios, clases, comisiones y materias en un mismo entorno para facilitar la organización académica.

Gestión de aulas

Permite asignar aulas, ordenar disponibilidad y reducir conflictos de superposición en la programación.

Usuarios y roles

Organiza perfiles, accesos y responsabilidades para operar el sistema con mayor control administrativo.

Difusión de horarios

Incluye agenda pública, horarios públicos y vistas tipo TV o pantallas para comunicar información académica.

Gestión de eventos académicos vinculados a la programación.
Consulta centralizada de horarios y asignación de aulas.
Publicación de información operativa para alumnos y personal.

Preguntas frecuentes

FAQ sobre GeClau

Respuestas breves sobre el alcance funcional de GeClau y su foco como software académico para universidades.

¿Qué es GeClau?

GeClau es un software de gestión académica desarrollado por Grupo6S para universidades, orientado a centralizar aulas, horarios y operación académica.

¿Qué procesos permite gestionar?

Permite gestionar aulas, horarios, clases, comisiones, materias, profesores, eventos, usuarios y roles, además de agenda pública, horarios públicos y asignación de aulas.

¿Está pensado para universidades?

Sí. GeClau está orientado principalmente a universidades y a la gestión de horarios, aulas y clases en ese contexto.

¿GeClau puede adaptarse a instituciones no universitarias?

GeClau está orientado principalmente a universidades. Su lógica de gestión de aulas, horarios y clases puede adaptarse a otras instituciones educativas, como colegios secundarios o primarios, según las necesidades y el alcance de implementación.

¿Grupo 6 Solutions ofrece una demo de GeClau?

Sí. El sitio enlaza una demo pública de GeClau y también ofrece contacto para solicitar acceso.
